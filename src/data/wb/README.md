# WB 中国跨境 FBS 计价资料

本目录用于独立的 WB 利润计算器和定价工具，不参与 Ozon 或历史订单利润重算。

## 官方物流来源

- 原表：https://static-basket-02.wbbasket.ru/vol20/China/warehouse_and_tarrifs/1026.pdf
- 生效日：2026-11-11；核对日：2026-11-12。
- 完整原件：`public/reference/wb-logistics-2026-11-11.pdf`。
- 结构化数据：`logistics-2026-11-11.json`，记录原件 SHA-256，包含全部 73 个唯一仓库编号。
- 提取中文表，并逐项交叉核对英文表中的 73 个仓库编号与四个费用字段。物流产品使用官方英文名称 WB Standard / WB Express，保留中文名称、WB Plus 标记、运输方式、承运货物、时效和仓库位置。
- 一个仓库编号是一条报价入口，不等于一家独立承运商。新版原表没有为所有仓库列出独立承运商名称，不推测承运商。默认合肥 382855 按用户确认显示 DPX，费率和限制仍以此仓编号的最新行计算。

计费重 = ceil(包裹实际克重 / 100) × 100。运费 = 计费公斤 × 当前档公斤费 + 每票费。此官方中国跨境表按实重计费，不套用 Ozon 体积重或计抛公式。计费重不超过 300g 时使用轻小件档，从 400g 使用另一档。尺寸限制逐仓匹配；多数仓限重 25kg，357322 单独限重 20kg。带电商品容量限制为 100Wh，具体是否承运还需依原表渠道名称、禁运目录及仓库要求核对。

常见费率：

| 入口 | ≤300g：元/kg + 元/票 | ≥400g：元/kg + 元/票 |
| --- | --- | --- |
| WB Standard（包括合肥 382855） | 58 + 2 | 43 + 8 |
| WB Plus 珲春 50072222、东莞 50131977 等 | 48 + 9 | 48 + 9 |
| 香港 325994 等 | 89 + 17 | 89 + 17 |
| 东莞 357322 | 122 + 19 | 122 + 19 |
| WB Plus 成都 50239292 | 48 + 30 | 48 + 30 |

不能把上表汇总值覆盖到所有仓；完整 73 行才是计算来源。后续更新应下载新官方原件、核对生效日及全表，新增版本并更新引用，保留旧原件。此任务不建立未经用户要求的定时同步任务。

中文轻小件栏另印有“限重1.9公斤”，与该栏 0.1–0.3kg 范围不一致；英文对应标题无此句。没有据此覆盖正文明确的总限重，保留原件供核对。

## 官方佣金来源

https://dev.wildberries.cn/docs/openapi/rates

通过当前企业内已核对身份的正式 WB 店铺，调用 `GET https://common-api.wildberries.cn/api/v1/tariffs/commission?locale=zh`，仅使用 `kgvpChina`，不使用俄罗斯本土或其他销售模式字段。结果按企业、店铺和授权摘要隔离，合并并发读取并缓存 12 分钟以遵守接口限频；读取前仍验证店铺所有权和有效授权。不返回 Token。缺少官方中国费率时不填入 Ozon 费率，提示按卖家后台手动填写。

## 公共费用约定

按本次用户要求，广告、退货率、每次退货损失、其他费、国内运费及贴单、尾程和提现沿用现有工具逻辑。尾程 2.5% 和既有提现公式是用户指定的共同测算约定，不代表本次核实了 WB 合同中另收这些费用。WB 中国卖家售价以人民币输入和输出，卢布仅供汇率参考。
