# 拼多多采购物流同步插件

独立于现有 Ozon 采集插件。采购人员在已登录的拼多多物流详情页点击插件图标，插件只同步订单号、快递单号、物流状态和最新轨迹到 ERP；不读取或上传 Cookie、密码、收货地址。同步时需另开一个已登录的 ERP 标签页，以该页面会话安全调用 ERP 专用接口。

在拼多多页面右下角点击“同步采购物流”，或点击浏览器插件图标，插件会收集当前已加载订单的物流详情并一次回传 ERP。ERP 只更新已保存拼多多订单号或快递单号的采购物流记录；未命中的订单会被统计，不会错误绑定。

在 Chrome 扩展程序页面开启开发者模式后，选择“加载已解压的扩展程序”，并选择本目录。
