# pivot-table

#### 介绍
ozon后台数据透视

#### 安装教程
在 Chrome 浏览器地址栏中输入：chrome://extensions

点击页面左上角的“加载已解压的扩展程序”按钮，在弹出的文件选择窗口中，选择解压后的插件文件夹（包含 manifest.json 的目录），点击“确定”即可

#### 使用说明
登录 Ozon 卖家后台：在浏览器中打开 Ozon 卖家后台网址，使用您的账户名和密码登录。

进入销售漏斗页面：登录成功后，在功能菜单中找到并点击“分析”或“数据分析”选项，进入 /app/analytics 页面。

跳转至商品销售页面：在销售漏斗页面基础上，继续跳转到 /app/analytics/graphs（我的商品销售页面），即可查看商品的销售图表数据。
