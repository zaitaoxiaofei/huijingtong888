# 旧登记采购工作台退役

2026-11-10 起只保留 `/procurement/workspace` 的当前库存采购工作台，移除“登记采购（旧）”导航和旧版登记界面的组件实现。没有删除采购、采购需求、到货、库存或历史成本数据，也没有撤销相关服务端接口。

- 旧 `mode=purchase` 链接自动移除旧模式参数，保留库存商品及其他上下文，进入当前工作台。
- `mode=arrivals` 继续进入采购待到货；采购批次记录和每日采购导出继续使用现有组件。
- 私信采购需求继续用企业鉴权引用接口查看，账号或企业变化时取消旧请求并清理显示。
- `review_product_id` 继续指向对应库存商品的历史核对弹窗，使用当前采购台账组件。

旧界面独有的源码快照断言随界面退役；采购服务端需求、供应、来源、成本及权限断言保留，另增加退役导航、旧链接及功能保留检查。当前工作台组件的采购和库存处理逻辑保持原实现。
