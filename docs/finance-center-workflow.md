# 财务中心：经营总览与表格报销

主导航保留经营总览、报销中心两个入口。普通企业成员只看到报销中心；企业负责人、管理员可看经营结果、工资导入及审批。平台账号也必须具有当前企业上下文才能使用新申请接口。

## 经营总览

默认展示今年累计收入、净利润、累计净利润率及费用与人工成本。月份点击后进入原经营账单，保留自选日期、订单、售后等现有明细。年度总览与月度账单复用相同利润和费用口径，累计净利润率采用累计利润除以累计收入。当月截至北京时间今日，未来月份显示尚未开始。历史月份不自动视为已关账。

采购成本的“明细”打开采购支出与库存资金抽屉；采购支出和当前库存快照不会再次扣减订单利润。公司、店铺归属、凭证及关账等历史功能收在财务设置中，旧接口和记录保留。

## 报销

1. 下载当前企业的报销模板，模板预填当前员工姓名，公司与报销类型可下拉选择。
2. 每行填写一笔费用：报销人、公司、类型、日期、事由、人民币金额、凭证截图、备注。
3. 在G列插入普通PNG/JPEG图片，图片左上角须位于对应明细行；每行最多10张截图。暂不支持WPS单元格图片、IMAGE/DISPIMG公式、截图链接和旧版 `.xls`。
4. 上传 `.xlsx` 后查看解析预览，确认提交后为待审批；每次最多100笔，文件不超过8MB。
5. 管理员审批通过或填写原因退回。通过时按明细费用日期原子写入经营费用；不增加付款流程，审批通过不代表已付款。

员工只能读取、导出本人申请。管理员可看当前企业的全部申请，按审批状态筛选最近200条。单个申请可导出含全部截图的Excel明细供留档；重新申报仍使用报销模板。相同语义内容的重复提交会被阻止，退回后需修改原表再上传。

申请和截图存储在企业隔离的申请表中，无公开附件URL。通过记录不可在旧人工费用入口单独修改或删除，避免申请金额与账单不一致。重复审批由数据库行锁和费用来源唯一键防止；包含已关账月份的整批审批会回滚。

## 工资

经营总览中的“工资表导入与汇总”支持下载工资模板、上传现有19列工资表。按工作表抬头、年份、月份识别多个公司和月份，只接受当前企业公司字典中的完整名称。

读取基本工资、单位缴费明细及小计、个人缴费明细及小计、个税、实发工资；校验小计和实发工资，不自行套用社保比例。Excel公式使用保存后的缓存结果，请在Excel/WPS中重新计算并保存后上传。每批最多500条。

人工成本为基本工资加单位承担费用，按工资月份最后一天入账；个人缴费与个税不重复计入成本。同公司同月份只允许一个待审批或已通过的导入批次，退回时释放月份占用。旧工资模块已有入账记录时，审批阻止重复计入。

## 数据与验证

新增 `finance_submissions`、`finance_submission_items`、`finance_imported_payroll_periods`，由初始化脚本及新服务首次使用时创建。新表企业字段均非空；费用沿用默认企业的历史归属约定。旧数据不被批量转换。

验证包括模板及内嵌图片往返、原始工资表读取、字段与金额错误、企业/人员权限、重复上传、并发审批、关账整批回滚、工资月份占用，以及年度和月度金额一致性。真实数据库测试只使用禁用网络的独立测试MySQL与随机临时库：

```sh
node --test test/finance-workbooks.test.js
TENANT_TEST_MYSQL_SOCKET=/path/to/isolated/mysql.sock node --test test/finance-submissions.mysql.test.js test/tenant-monthly-billing-mysql.test.js
node scripts/check-text-encoding.mjs
```
