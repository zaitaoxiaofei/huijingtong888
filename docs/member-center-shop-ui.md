# 会员中心与企业店铺界面

- 账号菜单保留一个会员中心入口。顶部企业密钥可查看、复制、生成或确认后重置；沿用原有权限和企业切换保护。
- 会员中心直接显示剩余时长、本期开始时间、到期时间和积分。点击时长可展开激活码输入；积分充值按钮展示联系服务人员登记的现有流程，不虚构线上支付。
- 当前没有套餐售价数据，价格显示联系服务人员确认。本期开始时间来自 subscription_started_at，不冒充最后付款或充值时间。
- 右上角“使用文档”单独打开可搜索的说明抽屉，收录激活、积分、插件和店铺授权说明。
- 企业店铺编辑按基本信息、Ozon 授权分组，广告及其他选填项默认折叠。负责人选择本企业已有账号；公司主体为经营主体；广告 Client Secret 与店铺 API Key 分别填写。
- 店铺提成输入为百分比，保存仍为 0–1 的 payout_rate。新增默认 0；显式 0 正确保留；更新未提供时保留旧值；已有店铺不批量修改。暂不实现自动分红或修改利润公式。
- 新填授权说明不再被当作 API Key；更新时继续兼容已有历史密钥保存方式，密钥留空不替换。

验证：72 项检查通过；完整前端构建、UTF-8 检查通过；浏览器假数据验证激活展开、积分入口、0% 保存、新增默认 0%、既有 33%、文档搜索、390px 窄屏无横向溢出。生产发布需独立批准。
