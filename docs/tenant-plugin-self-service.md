# 新企业插件绑定入口

会员中心增加“插件绑定 · 当前企业”，显示当前企业名称、编号、系统地址和采集归属说明。未激活时仍展示入口和步骤，提示先激活试用或会员；有效会员中的企业负责人或管理员可以生成、查看和复制本企业密钥。

1. 在 ERP 会员中心打开插件绑定，下载并安装采集插件。
2. 生成企业专属密钥，或查看已有可恢复密钥并复制。
3. 打开浏览器插件，在“企业专属密钥”输入框粘贴，点击“保存密钥”，在插件内确认连接成功。
4. 采集内容先进入本企业采集箱，生成或保存草稿后进入本企业草稿箱。同企业成员共享，其他企业不可读取。

插件按密钥确定企业归属，不跟随 ERP 网页切换企业自动改变。跨企业操作需更新插件密钥。重置会使旧密钥立即失效，必须确认后才能执行；查看已有密钥不会自动重置。

普通成员不显示生成、查看或重置按钮，由本企业负责人或管理员提供密钥。默认企业仍遵守既有规则，仅平台管理员管理其插件凭证。新入口复用现有企业鉴权接口，指定企业必须匹配当前会话，平台明确授权的管理路径除外。

密钥只保存在当前页面内存和短暂弹窗中，不写入持久浏览器存储。切换企业、移除角色、停用会员、离开会员页面或关闭弹窗后清除明文；旧企业的延迟响应不能展示到新企业。重置确认期间发生企业切换，不会旋转新企业的密钥。

插件程序及其 manifest 未修改，现有版本无需因此强制更新；只增加 ERP 页面入口。服务器已配置密钥加密服务，本次不修改加密配置、不自动生成或重置生产插件密钥。浏览器验收使用假密钥和内存剪贴板，不触及真实凭证。
