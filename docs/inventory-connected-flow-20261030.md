# 库存图标流程图

基线：最新远端release `187c844793aec6b0aa854e8329b7e8dd612b273e`。

沿用图标、关键数量和状态动效，恢复流程图的分支、汇合和反馈；不修改已验证的库存计算、接口和数据库。

- 采购申请 → 确认采购 → 在途 → 验收 → 本地实物。
- 本地实物并行分配到FBS订单和安全保障，扣除占用及保障后为本地可用；不把订单和保障画成顺序步骤。
- 本地可用连接FBP申请 → 锁定 → 发仓在途 → 签收入库 → 平台可用 → 平台订单 → 销售发货。
- FBP官方可用反馈安全目标，未覆盖缺口回到补货申请；FBS、本地保障或FBP存在采购净缺口时才显示返回采购申请的虚线。虚线反馈不代表另一次实物扣减。
- 连线使用独立SVG图层，按真实节点位置测量，节点文本及库存状态变化、容器尺寸变化后重新定位；卸载断开ResizeObserver和待执行帧。
- 保留摘要、SKU明细、原单据导航、键盘焦点、背景同步和减少动态效果。窄屏通过可聚焦的横向滚动区域保留完整连接关系，不拆成无连接的模块列表。
