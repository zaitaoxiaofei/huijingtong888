# 首批客户试用开通

当前适合采用受邀试用、人工发码的流程。自助注册与会员兑换不等于已接入在线支付，不会自动扣费；价格、收款及发码由服务人员处理。AI 额度独立配置，不随会员激活码自动赠送。

## 服务人员

1. 使用有平台授权的账号进入“企业与授权 → 会员激活码”，选择现有“7 天体验”套餐（实际天数、账号/店铺额度以该套餐配置为准）。不需要先替客户创建企业。
2. 点击“复制开通指引”发送给客户；生成激活码后，可点击“复制含激活码的开通指引”。完整码仅显示一次，请私下交给指定客户，不公开到群。
3. 客户自行注册独立企业，在会员中心兑换。不要让客户认领你们内部企业，也不要使用空间详情里的旧企业认领码或浏览器插件令牌代替会员激活码。
4. 试用结束后确认客户所需套餐，人工收款后发对应套餐的新码；续费保留剩余时长。当前没有自动支付、自动续扣和自助退款链路。

## 客户

1. 打开服务人员发来的注册链接，填写登录名、昵称、企业名称与密码。该链接通过 `#/login?register=1` 直接打开注册表单。
2. 在会员中心兑换收到的会员激活码，核对所属企业、会员期限和额度。
3. 进入“企业店铺”，填写自己的 Ozon Client ID 和 API Key。密钥只在系统表单填写，不在聊天中发送，也不借用其他客户的密钥。
4. 先执行“拉取新订单”，等待任务真正完成并核对数量；需要历史订单时再选择日期范围同步。
5. 企业 AI 额度配置后，上传一件真实产品的图片，执行模板工作流并人工检查产出。价格、包装参数在上架前填写。首次验收停在待上架，不发布商品。

## 本轮验收与限制

- 在本机关闭 TCP 的隔离 MySQL 上创建随机库和全新账号：注册、重新登录、未激活限制、平台发码、单次兑换、7 天试用、新客户创建店铺/资料、A/B 隔离已通过。订单同步和 AI 数据隔离分别使用隔离实库及受控外部接口替身验证；不代表真实 Ozon 授权或真实付费生图已通过。
- 没有使用真实客户的店铺密钥，没有发送真实付费模型任务，也没有发布商品。真实店铺授权和首件生成仍须在试点客户自己的企业中验收。
- 当前生产站点对匿名访问返回 401，保留内部站点访问验证。注册链接不绕过该保护。发给首批客户前，管理员需要先安排受邀访问方式；若要开放公网注册，另行审核并明确批准生产访问配置，不能直接关闭全站保护。
- 密码找回、在线支付及短信/邮箱真实性验证未在本轮验收中确认，不能向客户承诺已具备。
- 先前生产订单同步曾出现企业归属校验错误。该问题不能用本轮隔离测试当作已修复；真实首单同步仍是对外放量前的阻断检查。

## 发布

本轮只增加注册直达链接、平台客户开通指引和会员中心使用步骤，不改变注册权限、企业归属、套餐权益或站点访问保护。按 AGENTS.md，提交与本地验证完成后，需单独批准合并及 ECS 部署。
