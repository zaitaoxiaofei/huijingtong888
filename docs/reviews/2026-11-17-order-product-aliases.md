# 订单库存和采购信息中的商品别名

订单表格的库存信息区域新增悬浮提示，展示绑定库存及实际组成库存的名称、库存编号和商品别名；默认库存列保持原有布局。采购信息列直接展示实际实物库存的别名，多件商品逐项标明对应库存。虚拟组合没有产品 ID 时仅查实际子库存，不使用订单、SKU 或配方编号查询商品。

复用已有企业隔离的批量商品别名接口和前端共享状态，不新增数据库字段或写入接口。订单展示只读取别名；没有填写时显示“无”，读取失败可重试。已有库存编辑保存后共享状态可同步更新。

验证：16 项库存关联和订单采购检查通过；编码检查与生产前端构建通过。ego-browser 使用实际 OrdersTable 组件和本地测试数据验证库存区域默认没有别名行、悬浮显示商品身份及别名、采购列默认展示、套装逐件对应及无别名状态。生产部署须取得本次具体发布确认。
