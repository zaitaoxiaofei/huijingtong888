# 采购开票文件存储优化 1.5.16

存储位置统一记录在 docs/architecture/pdd-invoice-storage.md。MySQL 保存台账和文件索引；发票正文保存到企业/采购账号隔离的私有 OSS 对象；Chrome 保留工作缓存和用户选择的导出副本；ECS 旧文件仅兼容读取及显式迁移。

上传先校验私有 ACL、原站匿名访问拒绝、大小和 SHA-256，再短事务更新索引。失败不降级为磁盘写入；OSS网络操作不占用数据库行锁。旧附件先预检再迁移，保留原编号及本地副本；不会自动清理无引用对象或生产旧文件。提供只读备份引用清单导出工具。

新插件要求后台明确声明私有 OSS 存储协议，避免连接 1.5.15 旧后台时保存到磁盘。旧客户端仍可通过既有受保护接口下载文件；公司、台账、并发申请及卡住保护保持兼容。设置与记录显示 OSS 或旧系统附件，来源不混淆。

校验：161项聚焦测试通过；UTF-8、SQL参数和diff检查通过。覆盖跨企业拒绝、匿名访问泄露失败、OSS异常不改索引/不泄露SDK敏感参数、内容校验、旧附件幂等迁移与原件保留、备份清单脱敏、旧后台能力拦截。浏览器以模拟记录验证迁移调用先预检再确认，以及存储位置说明。

未对生产 OSS 写入测试对象、未迁移生产附件、未修改 bucket ACL/版本控制/生命周期配置。本次不部署 ECS，实际存储权限与备份恢复演练需在上线准备中核实，不能把模拟测试等同于生产权限验收。
