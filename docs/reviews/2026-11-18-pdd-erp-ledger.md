# 采购开票助手 1.5.15

当前问题：台账与账号备注仅存在本机，公司资料重复输入；混合状态全选阻止整批申请；串行队列慢，页面不返回消息时没有超时说明。

变更：复用企业插件密钥读取 finance_companies，明确选择开票主体；账号备注和逐单台账写入按 tenant_id/account_id 隔离的 MySQL JSON 台账，乐观版本冲突保护并发写入；官方发票附件可选本地或系统，系统文件保存在持久 uploads/pdd-invoice-private，需当前企业令牌取回。申请主体快照与当前账号选择分开保存。

队列默认并发2、可选1/2/4/8，逐单标签页及一次性授权校验保持有效；全状态全选自动筛出待申请。等待处理回执超过45秒明确暂停，提交过的请求只读核对，不自动重发；数据读取和ERP请求25秒、面板短请求12秒有错误反馈。界面显示最近响应时间、每批数量及处理窗口入口。

校验：141项聚焦测试通过，覆盖其他企业拒绝访问、版本冲突、私有附件去重及校验、ERP密钥复用、账号恢复不恢复登录、并发上限及不重复申请、卡死与授权后回执丢失。UTF-8、SQL参数和diff检查通过。浏览器使用模拟数据验证两个公司切换、混合全选只提交待申请、并发选项传递和暂停状态可见；没有新增真实开票申请，也未进行8路实单压测。已有8788服务占用端口，未重启或停止它；无关collector HTTP测试未计入本次141项通过结果。
