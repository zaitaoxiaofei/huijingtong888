# 商品别名

每个库存商品新增 `products.product_alias VARCHAR(500) NOT NULL DEFAULT ''`，空值显示“无”。新增库存和建品审批沿用现有 payload 保存此属性；库存列表新增独立列。采购必须/预估、到货批次、采购登记、验收入库、库存详情和 FBP 共用轻量别名组件，在库存信息中用灰色文字展示，并支持单独编辑及清空保存。共享库存身份操作的其他页面也会展示别名；FBP SKU 的实际组成库存逐件展示各自别名。

批量读取只返回当前企业商品的 ID 和别名，每次最多 200 个，避免逐行请求完整库存详情。所有入口写回同一个商品字段；同页面其他入口立即更新，重新打开页面重新读取。普通整表单编辑不写回别名，避免旧表单覆盖独立更新。保存使用事务锁和 expected_alias 比较，冲突返回 409。后端重新检查当前有效企业成员及库存编辑、采购或打包权限；跨企业写入拒绝，跨企业读取不返回数据。支持库存名称/关键词及共用工作台按别名搜索。
