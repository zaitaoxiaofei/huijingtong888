# 库存占用操作入口补齐

从最新远程发布分支 release/2026.10.21-task-brand @ 61f1ef5 开始开发。承接上一版 ef9ceec 筛选修复（本分支 cherry-pick 为08284a5），解决 mysql-cutover 头部导入冲突时同时保留 billingProfitTotals 与核实筛选导入；未覆盖并行账单修复。

用户补充要求：不能只有筛选和含糊的盘点入口；需要编辑库存、库存明细、更新数量、补采购记录，以及未绑定时绑定或创建库存。

## 行为

- 桌面和移动端共用同一操作组件；将“盘点更新数量”明确为“更新库存数量”，继续走已有实物数量、调整原因、凭证与幂等确认流程。
- “编辑库存”复用现有商品编辑组件，修改成本、克重等资料；不冒充数量调整。
- “库存明细”复用只读库存详情；编辑资料后刷新本页。
- “库存流水”直达已有流水页签；“核对／补采购记录”直达历史核对页签，分别显示缺采购来源和收货待核，保留关联已有采购、补收货和历史补录操作。不能根据销售单数减采购单数直接造采购缺口，也不自动新增库存或采购。
- 未绑定FBP项可绑定已有库存或创建库存并绑定。只读快照查找同店铺、同SKU未归档在线商品，后端原绑定接口再次验证企业、店铺与库存权限。无法确定来源时不猜测，提供该店铺在线商品核对入口。
- 创建库存复用建品表单与审批流程，并携带在线商品ID和SKU；申请待审批不显示为已创建或已绑定。允许从相似库存选择已有商品，仍需明确点击绑定。
- 权限不扩展：无库存写权限不显示编辑、数量更新、绑定和创建；无采购权限不显示采购补录或在途批次修改。切换企业关闭操作，不回填旧响应。
