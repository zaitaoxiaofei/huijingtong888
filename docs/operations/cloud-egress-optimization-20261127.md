# 公网流量费用优化（2026-11-27）

## 核查依据与范围

计费项明细显示 OSS 公网流出约 105.46 元、存储约 5.87 元，GET/PUT 和图片处理在此账单中为零。月概览与明细更新时间不同，不强行拼接为同一时点总额。11 月 23–26 日完整日的 OSS 和公网出口合计约 31.36 元。费用仍在出账，不能用今天未完整的数据推断最终日费。

ECS 网卡总流量包含 OSS 内网备份校验，不能直接乘公网单价。归档和业务素材的保留、完整性校验与恢复链维持原有要求；本次不删除 OSS 对象，不改生命周期，不调整服务器规格、不购买资源包。

## 实现

### 刊登图片完整校验复用

本桶公开内容寻址图片使用固定 5 分钟、最多 500 条的成功结果 LRU，并合并相同 URL 与校验策略的并发任务。首次仍连续两次完整公网下载；失败、截断、非 200、最终 URL 改变均不能登记成功缓存。外链、可变旧链接、私有目录、签名及变换参数不参与复用。每个调用者在缓存命中与等待共享结果前后分别复核自己的当前权限；缓存只保存公开下载结果，不保存企业授权或图片正文。

### 可重建图片缓存与接口压缩

图片代理和商品缩略图的两个专用缓存目录由发布目录链接到共享目录，避免正常发布后全部重新下载。仅缓存读取结果，上传文件、任务原图、归档及业务记录不在此目录。写入采用临时文件及原子重命名；代理正文与元数据校验字节数及摘要，不返回半写入内容。

代理缓存预算 128 MiB、缩略图 32 MiB。写入和过期处理有文件数、单文件、扫描范围与频率限制，繁忙或容量不足时跳过可选缓存写入。只处理两个目录中约定命名的普通再生缓存，未知文件与符号链接使写入拒绝，不能授权清理其他目录。

部署为 ERP 的反向代理 location 加载独立 gzip 片段，压缩大于 1 KiB 的 JSON、JS、CSS、SVG 等文本，保留内容和 API 契约。新配置须通过 `nginx -t`，失败恢复原配置；不改 TLS、身份权限或其他站点。正常发布仍需用户批准，Nginx reload 也属于生产配置变更。

图片代理凭证读取收紧为现有的公开内容寻址目录分类器。私有、未知、签名、变换及外部链接不能因缓存持久化获得服务端 OSS 读取权限，继续经过无凭证的公网读取边界。

### 视觉模型图片传输

直接把原图转为 base64 会把 OSS 下载费转为更贵的 ECS 出口，并增加约三分之一的传输字节，不能称作节费。

仅内网开启时，对本桶公开内容寻址 PNG 尝试静态 8 位无损 WebP 编码，不缩放、不改变模型路由、不改变生图输入或生成质量。ICC、动画、16 位、方向元数据等不能无损保持的输入维持原 URL。整个 data URL 的字节数必须不超过原图的 25%，同时每图最多 512 KiB、每次请求最多 2 MiB，否则保留原 URL。此门槛按当次账单 OSS 0.25–0.5 元/GB、EIP 0.8 元/GB计算，连同 base64 开销仍有余量；单价改变后须重新评估，不能无限外推收益。

同一请求的重复图片只内网读取和编码一次，但每次重复的 inline 值均计入实际传输预算。全局只允许一个可选预处理，繁忙请求保留原 URL，不排队持有大量图片。读取限 20 MiB、像素和编码时限均有限制，总预处理预算只控制是否开始下一张。网络读取失败不偷偷回退公网；可选编码失败可继续使用原先合法的 URL。预处理前后复核权限；重试复用处理结果，每次实际供应商调用仍经过原有额度和权限边界。
