# 自助注册与会员激活

账号使用登录名、显示名称和密码注册。注册不是邮箱验证：本版本不发送邮件或短信验证码，也不宣称邮箱或手机号已验证。登录名为 3–64 位字母、数字或 `. _ @ + -`，首位是字母或数字；密码遵循现有强度规则，最长 128 位。现有人员显示名称唯一约束仍保留，重复显示名称或登录名需更换后重试。

每次注册在一个事务中创建一个普通账号、独立企业及该企业明确的 owner 成员；岗位为 `operator`，不产生平台授权，不加入默认企业，不关联或移动既有账号/业务数据。企业起始状态是 `unactivated`，没有自动试用，子账号和店铺额度为零。注册按 IP 限流，注册事务失败会回滚人员及企业。原有站点访问密码保护仍适用，不因增加注册端点而关闭。

未激活或已到期用户可以登录、打开会员中心、修改本人资料、使用基础定价/利润计算器及本人外观偏好。服务端仅保留以下订阅豁免，随后仍经过原身份、岗位及企业隔离校验：

- `auth` 中按端点鉴权的本人资料、登录和会员接口。
- `GET tools/pricing/reference-rate`、`GET tools/pricing/rfbs-marketplace`、`GET tools/pricing/logistics-rules` 三个安全参考投影。
- `GET system/info`、`GET system/update-status` 及本人 `GET/POST user-preferences`。

其他业务接口仍要求有效订阅；原有岗位权限和高级功能隔离门禁不会因激活而开放。界面入口隐藏不能替代服务端校验。用户时间统一通过共享北京时间格式化工具显示，接口保留 UTC ISO 时间。

## 激活码与续费

新销售凭证为 `BD-` 开头的会员激活码，保存在独立的 `tenant_subscription_vouchers` 表。它与旧 `tenant_activation_codes` 的企业认领码、浏览器插件令牌完全分开。新兑换接口不接受旧 `OZ-` 码，不把任何码解释成加入其他企业的授权。

平台超级管理员在发码时选择有效套餐。凭证保存发码时套餐名称、类型、天数和账号/店铺额度的不可变快照；后续编辑套餐不会静默修改已发出的凭证。兑换截止默认发码起 30 天，可明确设置未来一年内的含时区时间；截止时间与会员到期时间是两个概念。凭证明文仅在发码响应显示一次，数据库只保存 SHA-256 哈希及后六位提示；列表最多返回最近 100 条且不返回哈希、完整码或密码。私密响应设 `Cache-Control: no-store`。

当前有效企业负责人在会员中心兑换。事务重新检查企业、启用账号和明确 owner 身份；锁定企业、成员及凭证行后仅允许成功使用一次，记录使用人、企业与时间。兑换只更新当前企业的套餐和额度，不创建、转移或删除成员、店铺或其他业务数据。未激活/已到期企业从兑换时开始计算期限；仍有效的有限期会员从 `max(现在, 当前到期时间)` 累加。并发兑换同一码只有一个成功；同企业同时使用两个不同码可依序累计。

企业已暂停或归档时不能通过激活码绕过管理员停用；原有长期授权无需兑换时长。降低套餐额度不删除既有数据，继续由现有账号/店铺服务阻止超额新增。AI 额度仍由原企业 AI 额度流程单独配置，本凭证不包含或推断 AI 额度。

接口契约维护于 `src/server/api-docs.js` 并生成到 `docs/BACKEND_API_REFERENCE.md`：`POST /api/auth/register`、`GET /api/auth/membership`、`POST /api/auth/activate` 和平台 `GET/POST/DELETE /api/tenants/subscription-vouchers`。平台管理服务每次从数据库重新校验有效平台授权，不能仅信任旧会话标记。

## 数据库迁移与发布

全新数据库的 `scripts/init-mysql-schema.mjs` 包含新表。已有 ECS 必须在备份成功后、候选服务上线前执行管理员迁移。默认模式只检查表、InnoDB、字段及唯一索引，不修改 schema 或任何业务数据：

```sh
node scripts/migrate-subscription-vouchers.mjs
```

应用模式必须显式指定本机管理员 socket；可另传 `--database=目标数据库`。不提供数据库参数时使用当前发布配置中的数据库。脚本只新增缺失表，不重新分类账号、不修改旧激活码、企业套餐或成员；同名但不兼容的表会拒绝应用，需人工核对：

```sh
node scripts/migrate-subscription-vouchers.mjs --apply --mysql-admin-socket=/var/run/mysqld/mysqld.sock
```

迁移可重复运行，并使用目标数据库范围的迁移锁。应用服务只读验证此表是否已准备，不使用应用凭据自动建表；缺失/不兼容时会员功能返回可操作的 503 迁移提示。正式 ECS 流程已将迁移加入备份后的数据库维护清单；跳过数据库维护时必须先确认该表已就绪。仅有源码、构建或测试不代表已经发布。

## 验证

`test/self-service-membership.test.js` 验证输入、事务失败回滚、权限、套餐快照、时长及精确订阅白名单。`test/self-service-membership-mysql.test.js` 使用明确的 `TENANT_TEST_MYSQL_SOCKET`，在关闭 TCP 的独立 MySQL 上创建/删除随机测试库，实际验证密码哈希、隔离注册、单码并发兑换、不同码并发续费、作废/到期与撤权。`test/self-service-membership-http-mysql.test.js` 仅在本地 8788 启动同样随机库的临时子服务，验证注册/重登录、未激活基础页面 API、业务 402、平台发码和激活后访问链路；结束时停止子服务并清理测试库。未指定独立实例时实库测试明确跳过，不能据此宣称实库通过。
