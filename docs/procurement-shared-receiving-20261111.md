# 采购共享收货调整（2026-11-11）

采购登记完成后，采购和仓库立即在同一张「采购收货」表看到未完成批次。原待到货、待验收入口兼容进入该表，通过状态筛选查看工作，不再要求采购先确认到货。

| 操作 | 允许岗位 | 业务影响 |
| --- | --- | --- |
| 提醒到货 | 采购 | 记录提醒人、时间和选填说明，不确认实物、不增库存 |
| 确认实物到货 | 采购或仓库打包 | 记录实际到货数量，不增库存 |
| 验收入库 | 仓库打包；兼岗人员可操作 | 只增加本次合格实收数量，可直接处理尚未标到货批次 |

保留企业管理员原有管理权限。采购专岗的正常入库、旧接口和补录采购增库入口均在后端复核仓库权限；库存编辑、盘点、金额更正和不增库的历史来源解释保持各自权限。

电脑和手机同步提供全部未完成、待到货、已提醒、待验收筛选；保留北京采购日期分组、最早未完成优先、红绿角标、批量处理、库存编辑和历史版本。正式采购明细展示总采购、未到货、待验收、已入库累计数量；没有可靠关联的历史批次不推测总量。
