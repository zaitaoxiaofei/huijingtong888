# 数据备份与迁移说明

这份文档只保留当前有效原则：

- 当前系统运行数据库是 MySQL
- 不再使用 SQLite 数据文件作为运行时数据源
- 不再参考旧的 SQLite WAL 备份与迁移流程

如果需要备份、迁移或恢复数据，请按当前 MySQL 部署脚本和运维脚本执行，不要再复制 `*.sqlite`、`*.sqlite-wal`、`*.sqlite-shm` 之类的历史文件。

建议：

- 先确认 `.env` 中的 MySQL 连接配置正确
- 使用当前部署目录下的 MySQL 备份方案
- 在恢复前停止正在运行的服务
- 恢复后先验证核心业务数据，再恢复外部访问

如果后续需要正式的 MySQL 备份/恢复运行手册，建议单独新增一份 MySQL 文档，而不是继续沿用旧 SQLite 说明。
