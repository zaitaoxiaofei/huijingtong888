# 订单作业台待办

> 目标：把订单追踪从“看订单”升级成“处理订单”的工作台。订单页负责发现问题和处理动作，出库表只保留库存流水和复核记录。

## 第一阶段：订单作业台骨架

- [x] 状态标签重排：所有订单、待绑定 SKU、库存不足、可出库/已处理、运输中、已签收、已取消。
- [x] 订单表列重组：订单信息、商品/SKU、库存处理、金额/利润、物流、时间。
- [x] 每个 SKU 显示绑定状态、对应库存产品、订单数量、当前库存和缺口。
- [x] 未绑定 SKU 保留“去绑定”和“创建库存”入口，已绑定产品可直接跳到库存表。

## 第二阶段：异常优先处理

- [x] 将未绑定、库存不足、取消、超时发货这些异常统一成可筛选的处理队列。
- [x] 订单数量、订单金额、店铺、订单号放在同一行筛选区，减少页面空行。
- [x] 刷新按钮必须重新拉取当前页数据，字段显示只保留真正需要自定义的页面。

## 第三阶段：成本和利润

- [x] 订单利润按绑定库存产品的历史采购均价、订单售价、佣金、物流费用计算。
- [x] 取消统计拆成取消件数、取消订单数、取消金额，避免一个字段混着解释。
- [x] 产品库存表中的销售额、利润、取消统计全部从本地订单库汇总，并在同步后自动更新。

## 第四阶段：出库流水归位

- [x] 出库表默认只展示近 30 天库存流水，分页统一在右下角。
- [x] 同步订单时自动新增/更新/取消出库流水，保证本地数据库可追溯。
- [x] 出库表不再承担订单作业入口，只做库存扣减记录、异常复核和审计。
