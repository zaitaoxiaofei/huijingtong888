# 手机搜索与分页交互（2026-11-02）

## 使用方式

- 库存、采购、收货、采购添加商品及订单绑定库存共用 MobileInventorySearch。
- 首行左侧搜索方式，右侧输入框；默认库存 ID 精确搜索（如 1-23）。可以切换模糊搜索、SKU／货号、产品名称。
- 第二行统一为查询、精确搜索、重置；采购页另有刷新、登记采购，保持同排。
- 精确搜索以弹框选择库存类型、核心品名、汽车品牌、车型、颜色、款式、材质、工艺和产品名称。编辑为暂存，取消不会修改原条件；应用搜索清空旧输入关键词，使用所选结构化条件。
- 绑定库存不自动用 Ozon 俄文长标题作为库存 ID 查询，商品参考信息仍可展开查看。
- MobilePagination 保持固定底部，数量、每页条数、上一页、当前／总页数、下一页都在同一行；支持 20/50/100 条与直接跳页。切换条数回到第一页。
- 绑定候选库存的分页移至弹框固定底部，共用上述组件；列表独立滚动，选择的商品不因翻页丢失。

## 边界

仅调整手机组件交互、查询默认值和显示。复用现有库存查询参数，不改变采购写入、库存扣减、权限、企业隔离和财务计算。

## 验证

- 真实 Vue 组件回归共 59 项通过，覆盖筛选暂存／应用、绑定默认 ID、查询作用域、失败保留选择、分页边界、加载中禁止翻页等。
- npm run build:frontend、npm run check:encoding 通过。
- ego-browser 使用本地 8788 合成数据页面；320/375/390/430px 无横向溢出，搜索为同排，分页高度 47px。375px 采购页五个按钮同排。
- 实际操作验证取消筛选不生效、应用筛选、下一页、切换 50 条回第一页、绑定候选 50 条与嵌套精确筛选弹框。无 Vue 运行错误。
