# 手机采购单层登记交互（2026-11-03）

## 使用流程

登记采购直接在采购弹框顶部搜索库存，结果在当前弹框内显示。加入后自动收起结果、滚动到新加入的商品；件数和货款直接填写，继续在顶部搜索可添加下一项。无需进入添加子页面再返回。已选按钮可返回本次采购商品区域。

运费、采购链接、价格变动原因在各商品内按需展开；采购平台、平台订单号、快递单号和凭证集中按需展开。默认平台仍为1688。提交异常会保留内容，价格原因仍按原规则提交。底部固定显示项数、合计与确认登记。

查询和选择商品时收起键盘。数量、货款等字段聚焦及可见视口缩小时，滚动当前采购内容区让输入保持可见；不滚动整个页面。原采购幂等标识、权限、企业隔离及库存写入规则保持不变。
