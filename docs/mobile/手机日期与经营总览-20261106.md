# 手机日期查询与经营总览

开发基线：`release/2026.10.21-task-brand` @ `734f67a84fd66d0a96cc7ced12f4433143d0e575`。本轮用户已明确授权本地功能验证通过后合并最新 release、部署 ECS 并验收；后续仍须核对并发发布、精确合并提交及生产版本。

## 页面与口径

- 手机首页保留原指标，增加今天、昨天和指定日期。日期以北京日历为准，按所选日查询，切换时清空旧日数据并忽略迟到响应。
- 首页的月累计统计从所选日所在月的月初截止所选日，明确展示区间；订单利润与账单经营净利润分别标注。
- 广告若使用早于所选日的已有快照，显示实际广告数据日。库存占用始终是当前库存快照，历史日/月不能称为期末库存。
- 首页增加经营总览入口，保留原五项底部导航。经营总览默认今年，展示年度累计收入、经营净利润、累计净利率、费用与人工及各月概况；可切换年份。
- 点击月份进入手机月度账单，继续携带公司、店铺和月份；账单支持直接选择月份，适配手机卡片，不跳转到电脑版。
- 年度及月账单复用电脑端 `monthly-billing-details` 接口和现有费用、工资及利润口径，不修改冻结利润公式、不重算历史数据、不重复扣减采购或库存占用。
- 财务页面沿用经营总览的当前企业负责人/管理员权限，普通员工仍只收到首页允许的指标；请求中的企业参数不能替代会话企业。

## 状态与边界

- 手机日期参数严格校验；非法日、未来日不启动指标重建。桌面原接口日期兼容行为保持。
- 当月账单截止北京今日，历史月份按整月；未来月份显示尚未开始。历史月份本身不代表已关账。
- 未加载、缺月份、读取失败显示未知或明确错误，不能伪装成零。真实查询结果为零才展示零；零订单也可能有工资或经营费用。
- 年度净利率使用累计净利润除以累计收入，不能相加各月比率。公司或店铺筛选保持原 API 语义。
- 日期、月份、企业或权限切换后，旧请求不能覆盖当前页面；退出页面停止轮询和未完成读取。

## 验证要求

- 日期：北京跨日/跨月/跨年、昨天、指定日、闰年二月、无参数及非法/未来日。
- 手机浏览器：375/390/430px，快速切日/月、失败后重试、返回总览保留筛选、禁止财务权限的账号、无横向溢出。
- 财务：独立 TCP 禁用 MySQL 的年度/月度口径、企业隔离、费用无订单、北京边界与库存资金现有回归。
- 发布：源码与正常构建流程，UTF-8、SQL 绑定和相关测试通过；从精确合并提交打包；ECS 只读验证当天/历史日、经营总览和指定月账单，记录实际限制。

## 本地验证结果

124 项相关单元/组件/权限回归通过，另有独立 MySQL 月度财务 14 项及手机采购/财务 9 项通过，均无失败或跳过。真实 Chrome 的 1 个完整场景验证 375/390/430px、日期快切与迟到响应、年度/月度筛选传递、空月份/未来月份恢复、零订单工资、缺月未知、失败重试及无财务权限账号；同时确认新财务页面打开后位于滚动容器顶部。前端完整构建通过。
