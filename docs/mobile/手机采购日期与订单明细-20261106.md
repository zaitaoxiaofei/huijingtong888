# 手机采购日期与订单明细

本轮调整：采购待到货、到货待验收的日期导航和批量操作，以及发货订单利润明细和打印时间。两端采购日期均按北京日历，等待最久的未完成采购优先；没有当前队列待办的日期自动收起。完整采购行为约束见 [采购维护说明](../procurement-module-maintenance.md)。

## 手机操作

- 日期按月份分组，日按钮显示 `6号`，保留完整日期的无障碍名称。今天和昨天的剩余批次数用绿色，前天及更早用红色。旧的未完成日期继续保留，日期内独立分页。
- 支持勾选、全选本页、批量确认到货和批量验收入库。切日期、状态、搜索或页码时清空选择，防止操作到不可见的旧选择。
- 到货数量默认全量，填少则拆分保留余量；到货说明选填。到货不会增加实物库存。验收仍需核对实收数量、差异原因及入库影响，照片选填并归属各自批次；上传失败必须重试或移除后继续。
- 没有采购岗位不能确认到货。验收入库沿用采购或仓库岗位权限；未确认到货、套装内容待核或组成错误不能绕过校验直接入库。

## 订单详情

- 手机利润明细读取电脑端相同的 `profit_detail_snapshot`，复用 `buildOrderProfitDetail`。显示整单预估利润、结算状态、销售额、成本与费用逐项的预估、真实、差异及说明。
- 不从第一个商品推算整单，不将缺失输入伪装成 0。真实的 0 保持显示；尚未完成结算显示待结算。计算版本和汇率依据保留在默认折叠区。
- 不更改冻结利润公式、物流计费、历史分摊或利润写入逻辑，不触发重算。
- 发货列表已打印订单显示 `printed_at` 的北京时间，即最近一次确认已打印的时间。未打印不显示时间；时间无效则明确待核实，不用下单或更新时间代替。

## 验证范围

使用真实 Vue 页面与本地模拟接口验证手机宽度、日期选择、批量到货及收货、照片失败重试、订单多商品利润明细和打印时间；使用独立禁用 TCP 的 MySQL 测试采购日期、分批余量、入库及企业隔离。线上验收仅做业务只读检查，不提交真实采购或入库。浏览器手机视口测试不能代替 iPhone/Android 真机相机、键盘和打印设备验收。
