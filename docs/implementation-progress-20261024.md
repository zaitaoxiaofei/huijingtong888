# 长期优化实施进度

本文件区分“本地代码/测试完成”与“生产启用”。首批 `e6ba613` 及补充正式 release `a1ef0f7` 均已部署 ECS，当前生产版本为 `2026.10.24-priority-a1ef0f7`。本轮没有执行生产历史删除，也没有开通外部付费 AI 或冻结草稿新写入。

## 已确定的新增业务规则

2026-10-24 用户确认：AI 按成功生成结果扣费，自动重试不重复扣费，明确失败释放积分，结果未知先待核对。具体积分价格由平台设置，不自动把内部供应商成本换成客户售价。

## 继续实施，不得误报完成的项目

1. 冻结内容库的完整消费者已接线；继续验证实际发布内容一致，以及上一可回滚版本也具备读取能力，再按企业开启新写入。保留旧格式读取及历史图片意图，旧草稿不随部署自动瘦身。
2. 完成 AI 业务入口到积分执行模块的接入、持久任务恢复、价格配置/员工余额交互和服务部署边界；目前内核不能冒充完整收费产品。
3. 每批增量分别构建及验证；当前仍在收口草稿轻量响应去重和独立最终AI交付模块，不把未接入worker的模块当作可用产品。
4. 订单统计继续优化大范围采购覆盖读取，并验证稳定负载；已安装索引不等于解决全部性能。生产继续只从干净且已推送的release正式发布。
5. 历史删除需用户确认具体清单；数据库目标结构/引用完整及定向恢复仍须实测。真实 Ozon 发布/付费 AI/实物收发验收与替身验收分开记录。
