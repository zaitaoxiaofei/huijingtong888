# Ozon 财务原件按月下载

统一采集插件 1.5.8 增加“财务原件下载 · 按店铺和月份”入口，打开独立扩展页面。此版本只收集原件及来源清单，不解析会计项目、不写财务金额、不调整订单利润，也不自动上传 ERP。无需提供或向 ERP 转交 Seller 登录凭据。

## 使用

1. 在已登录的 Ozon Seller 打开“财务 → 文件”。
2. 点击插件弹窗中的“财务原件下载”，选中对应后台页面和月份。
3. 点击“识别店铺并读取目录”。从当前页面读取 `sc_company_id` 及可见的目录名称，带同一个店铺上下文访问目录接口；页面目录数量变化时停止并提示适配。
4. 检查全部目录及子目录的文件数，勾选需要下载的目录。空目录与读取失败分开显示。
5. 可选择电脑文件夹；未选择时写入浏览器默认下载目录的 `Ozon财务原件`。浏览器的文件夹选择权限由使用者在选择器中授予。
6. 点击下载，保持扩展页面打开。按目录逐份生成、轮询、下载、验证格式并保存。保存完成后才标记成功，失败项可在同一页面重试。选择另一个保存文件夹时重置成功标记，便于完整复制。
7. 每轮保存一份带时间编号的 JSON 清单，含月份依据、原始目录、原件元数据、下载路径、错误、字节数和 SHA256。重新扫描会重建内存任务；在自选文件夹内遇到相同内容直接复用，不同内容的同名文件拒绝覆盖。默认浏览器下载由 Chrome 避免文件名冲突。

保存层级：`店铺ID / YYYY-MM / Ozon原目录 / 子目录 / 原件编号_类型_原文件名`。原名在清单中完整保留，落盘路径移除非法字符并限制单段长度。

## 目录覆盖

10 个原始目录、15 个子目录：综合服务、销售报告（结算单据及参考信息）、向法人销售（销售登记册及已生成税务附件）、合作伙伴报告（报告及发票）、分析报告、赔偿、保证金与罚款、扣款与付款账单、对账单（平台出具及已申请）、FBS 发运关联单据。

月份严格按列表的文件日期筛选，不推断业务所属月。例如十月开具的季度对账单仍保留七月至九月的原名及原始信息。第一版不自动申请新的对账单、签署文件、批准或拒绝文件，也不自动生成扣款每日文件压缩档；没有已列出的原件时提示本月未列出文件。

Ozon 下载存在 ERP 文件生成、billing 文件生成、直达下载和 FBS Base64 响应等协议，按已确认类型分派。未知类型显示未适配，不通过试探接口或猜测金额消化错误。FBS 请求达到 999 条上限时拒绝声称完整。仅接受 PDF、XLSX、ZIP 文件头，单文件最多 40MB；正文及压缩包内容的财务分析不在此版本范围内。

每次请求前后检查当前店铺 ID；切换店铺时停止保存。目录/月份/语言变化后必须重新扫描。插件不主动切换或重用正在运行其他采集任务的后台页。新增下载权限用于默认下载目录保存，旧版商品和分析功能保持原消息协议，更新仍为可选。

## 多月份与主体归档（1.5.9，本地待发布）

弹窗入口改为“财务原件归档 · 多月份与主体归属”，旧单月入口保留。新入口需要同时打开已登录ERP与当前店铺的Ozon财务文件页面，并选择电脑上的统一保存目录。可选择全年或1—10月，也可逐月勾选；检查后默认只选择本地缺失或未完成月份。校验完整的旧版资料另标记需要复用归类，可复用原件而不重复从Ozon下载。

- “已有”需要清单、全部15个子目录扫描状态及每份实际原件的SHA256均通过；空文件夹、缺件、被修改的文件、部分目录、空报告月、中途停止均不视为完整月份。当前结果是本地归档快照，补开和更正资料需手动选择全量重新下载。
- 切换“全部重新下载并覆盖”后重新勾选可处理月份；只替换所选月份中当前平台文件对应的同名原件，不清空目录、不删除手工资料或其他月份。缺失模式遇到内容不同的同名文件会提示选择覆盖模式。
- 主体目录为 `公司名称__公司ID/店铺名称__店铺ID/YYYY-MM/Ozon官方目录/子目录/文件`。俄英原件用语言标识区分，原始文件名仍在索引中保存。每月的 `归档清单_ru.json` 或 `归档清单_en.json` 以及根目录 `_Ozon原件索引.json` 保留企业、主体、店铺、月份、官方文件编号、目录、相对路径、文件SHA256和证据ID，供后续分类汇总引用。
- 公司归属从 `GET /api/finance-center/document-archive-context?ozon_company_id=...&months=...` 只读取得。接口重新验证成员和财务权限，以会话企业限定店铺、公司及绑定查询，只返回名称、ID、税号和生效月份，不返回店铺API密钥。不能用客户端提交的公司名替换服务器绑定。
- 月份按既有 `finance_shop_company_assignments` 生效日期核对。缺少归属、重叠、月中跨主体或不覆盖整月的月份单独提示到财务设置补齐/核对，不自行归类。每月下载前与最终确认前重新校验ERP绑定；发生变化时保留未完成状态。
- 当前操作针对所选已登录店铺，其他店铺在切换/选择其后台页面后写入同一个保存根目录，按各自主体及店铺分别归档；不自动切换Ozon账号。数据仍保存在电脑，不上传原件或增加ERP财务金额。文件存在与否以选定电脑目录为准，不把ERP账单记录视为本地已下载。
- 同一扩展使用Web Locks避免并行页面同时写总索引。重新检查后恢复未完成的月份；保存文件夹授权由浏览器选择器授予，不持久化ERP或Ozon登录凭据。

本地验证：53项针对性测试通过，含12月选中而1—10月完整时只下载11、12月，显式全量覆盖12个月、停止、绑定变化、旧目录复用、文件校验、跨企业隔离、既有单月下载及弹窗兼容。亿狗浏览器受控页面验证了全年选择、默认仅勾选11/12月、补缺下载，以及全量模式重新勾选12个月；全量实际执行由受控整流程测试验证。另以只读文件系统适配器对上一版真实27份原件验证旧归档兼容，未对真实公司绑定作占位推断、未改写原件。UTF-8编码与SQL占位参数检查通过。

新接口尚未部署，不能将本地受控验收称为线上多月份归档成功。正式使用需按发布流程同时发布后台和1.5.9插件；后台未更新时新页面明确提示，旧单月入口仍可用。
