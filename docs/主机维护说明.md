## 日常操作

### 1. 启动服务

点击：

- `启动 ERP 云端服务`

作用：

- 启动 ERP 服务
- 启动 Cloudflare Tunnel

### 2. 更新系统

点击：

- `更新 ERP 云端服务`

作用：

1. 停止 ERP 服务
2. 停止 Tunnel
3. 重新构建 `dist/deploy`
4. 重新启动 ERP 服务
5. 重新启动 Tunnel

### 3. 停止服务

点击：

- `停止 ERP 云端服务`

## 桌面版用途

桌面版主要用于需要本机能力的功能，比如：

- Ozon 广告后台自动调价
- 以后可能加入的打印、本地文件能力

普通日常使用，优先走浏览器版。
