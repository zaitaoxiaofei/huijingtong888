# 采购开票助手存储约定（1.5.16）

本约定覆盖采购开票助手的数据及文件，不把 ERP 其他模块的既有文件批量搬迁。

| 内容 | 权威位置 | 电脑或 ECS 上的用途 |
| --- | --- | --- |
| ERP 公司名称、税号、公司 ID | MySQL finance_companies | 插件读取当前企业资料，缓存不是权威来源 |
| 采购账号备注、订单、开票状态、金额、时间、失败原因、申请主体快照 | MySQL pdd_invoice_accounts | Chrome 保存工作缓存与未同步结果，不接收或恢复拼多多 Cookie |
| 发票原图、PDF | 私有 OSS 对象 | ECS 新写入不落长期文件，用户可另选下载至电脑 |
| 附件编号、大小、SHA-256、格式、OSS bucket/region/key/versionId、关联订单 | MySQL 台账的 cloudFiles 索引 | 不存文件正文、不存公开链接、不存 OSS 密钥 |
| 商品缩略图 | 台账保存平台来源 URL | 当前只用于展示，不等同于永久图片归档；当前版本不自动复制所有商品主图至 OSS |
| CSV 导出及用户选择的本地发票副本 | 用户电脑的下载目录 | 是用户副本，不替代系统数据库与 OSS 归档 |
| 老版系统附件 | ECS 持久 uploads/pdd-invoice-private/企业ID/ | 仅兼容读取和显式迁移；迁移后不自动删除 |
| 企业插件密钥、拼多多会话 | 插件配置及浏览器会话 | 不写入业务台账、附件索引、导出清单或 OSS 对象 |

## OSS 命名和授权

使用 ERP 现有 OSS 配置，新增附件只允许私有归档。对象键固定为：

`private/tenants/{tenantId}/pdd-invoices/{accountId}/{sha256}.{ext}`

企业 ID 来自已验证的插件密钥，不接受客户端传入的企业归属。内容寻址在同企业、同采购账号内去重，不跨企业复用索引。文件限 5MB，仅接收识别出的 PNG/JPEG/PDF；图片与 PDF 在名称中明确区分。

上传写入 private ACL、private/no-store 缓存头；完成前检查实际私有权限及 OSS 原站匿名读取被拒绝，并回读大小和 SHA-256。只有验证成功才更新 MySQL 索引。OSS 不可用或配置不完整时明确失败，不自动降级为服务器磁盘保存。

下载通过企业鉴权接口代理并重新校验索引归属、大小与 SHA-256；不向浏览器提供永久公开 URL，也不依赖商品图片的公共 CDN。当前协议继续返回受保护的 base64 文件，兼容 1.5.15 客户端。OSS 读写凭据只在服务器使用。

## 写入失败和一致性

先在 SQL 事务外上传和校验，再短事务更新账号索引，避免网络请求长期占用数据库锁。重复上传同一内容可复用已校验对象，更新索引保留附件 ID。上传失败不改索引；索引提交失败不擅自删除可能被其他记录引用的 OSS 对象，后续重试可复用。无引用对象仅能在核对清单、引用关系及备份后清理，本版不执行自动清理。

若发现新建对象可匿名读取，会尝试撤回该次新建对象并拒绝关联；撤回失败仍是归档失败，需管理员修正权限和核对该对象。不能把 ACL 检查或匿名拒绝检查等同于 OSS 备份。

## 旧文件迁移

1. 读取当前企业、采购账号、订单和附件索引，核对本地文件大小及 SHA-256。
2. 默认仅预检，不上传、不改索引。
3. 用户明确确认此文件迁移后，上传私有 OSS 并完成隐私、大小和哈希校验。
4. 短事务重新核对订单归属，成功后更新原附件 ID 的存储指针。
5. 保留本地原件；再次迁移是幂等校验。旧文件缺失或损坏时保留台账、显示原因，不能标为迁移成功。

界面在旧系统附件旁提供逐份迁移入口，不自动批量迁移生产资料。改变 bucket/region 前必须保留原配置与原 bucket，并另行完成受审核的对象搬迁和索引迁移；不会猜测新地址读取历史文件。

## 备份与恢复边界

数据库备份保存台账及对象索引；OSS 对象保留文件正文。仅有数据库备份不能恢复发票文件，仅有 OSS 也不能恢复完整台账。

上线前由管理员核实 OSS 私有策略、版本控制或独立对象备份及保留策略，并以实际账号测试无签名访问拒绝。仓库工具可导出指定企业的对象引用清单，含 key、versionId、大小和哈希，用于配对数据库备份核对。

恢复顺序是恢复数据库备份及对象引用清单，再恢复对应 OSS 对象，最后逐个核对大小、SHA-256 和私有访问。恢复演练通过前不删除 ECS 的旧副本，不变更 OSS 生命周期规则。本版没有修改生产 OSS 配置、自动开启版本控制或宣称备份已经完成。

引用清单导出示例（123替换为明确要备份的企业ID，输出目录需事先准备且保持私有）：

```sh
node scripts/export-pdd-invoice-storage-manifest.mjs --tenant-id=123 --output=/secure/backup/pdd-file-references.json
```

该工具只读指定企业，不创建或迁移数据表，不复制密钥或文件正文；输出文件为0600且不覆盖已有文件。它是备份核对材料，不是对象备份本身。
