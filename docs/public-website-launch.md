# 官网公开发布范围

本次只发布官网首页、套餐价格、使用文档及账号注册/登录入口。采用白色、浅灰蓝和系统办公深蓝；产品图来自系统真实经营总览组件，数值为演示数据。

公开路径：`/`、`/pricing`、`/docs`、`/register`、`/login`，以及明确列出的后台登录壳和官网图片。后台业务 API 保留会话验证、企业隔离、岗位权限和套餐验证；不开放任意上传文件、内部文档或旧扫码登录接口。

通过 `SELF_SERVICE_PUBLIC_ENABLED=1` 开启公开入口；默认关闭。该开关是此次 ECS 发布唯一需要调整的配置。现有企业和店铺授权、员工权限不变。注册创建独立企业，通过会员中心联系开通和兑换激活码，年团队版展示价格 ¥3999。

微信、支付宝和自动充值代码不在此发布分支中，没有支付接口、支付后台任务或新增支付依赖；不做支付数据库迁移。官网明确说明内测期间暂未开放在线支付。

发布前需从合并后的准确 release 提交构建并验收发布包；远端发布头和当前生产提交必须重查，发布锁防止覆盖其他窗口。ECS 配置开启及具体版本发布需按 AGENTS.md 获批后执行。回退可恢复上一发布版本并移除/关闭公开开关。
