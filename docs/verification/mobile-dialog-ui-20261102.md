# 手机绑定、账号与业务弹框

基线：远端 `release/2026.10.21-task-brand` 的 `eba9adb9c2faf9d1df670e22d695e6239fe9ca5e`，包含并发窗口的手机版和可用资金改动。

## 改动

- 手机弹框使用公共容器：标题和操作区固定，中间内容滚动；按 Visual Viewport 更新高度和偏移，兼容键盘占用和安全区。短物流表单保留紧凑尺寸，长表单与选品在手机上使用全屏布局。
- 绑定产品采用20条分页、库存ID/SKU精确搜索、折叠结构化筛选、单品/配件/套装标识。当前页本地实物和可用量使用现有轻量投影；未知数量不显示为零。负责人候选按需加载。
- 绑定选择跨页保留，库存详情在上层打开，关闭后回到原列表；空结果、查询失败和提交失败都有明确状态。补充请求版本和企业上下文检查，阻止迟到响应覆盖新搜索。
- 我的页面改成身份摘要和设置入口，头像保持64×64。资料和密码分开编辑；取消密码编辑会清空输入。
- 采购选品使用独立面板，库存详情返回后采购表内容保留。采购登记、盘点、物流、验收入库接入公共布局；桌面验收入库继续使用原 ElDialog。

## 验证

43项相关 Node 检查通过，覆盖手机权限、首屏、搜索参数、跨页保留、过期响应隔离、密码清理、绑定失败保留和重复确认防护。生产前端构建、前端安全检查、UTF-8和差异空白检查通过。

`test/fixtures/mobile-dialog-preview.js` 使用真实手机组件和合成API，在本地8788验证，不连接生产数据。Ego浏览器检查包括：

- 360、390、430px宽度下账号头像为64×64；账号首页不铺开密码表单。
- 绑定页在360×480、390×844、430×932下底部按钮均在视口内。
- 绑定跨页选择及库存详情返回保留选择；无结果提示正常；模拟503提交失败后选择保留。
- 采购表经过选品、库存详情和返回后，采购订单号、数量和货款保留；模拟503后仍保留，可按原请求标识核对重试。
- 360×480下，密码、采购、验收入库及物流操作区不超出视口；相关页面无Vue运行错误。

缩小可视区域用于模拟键盘占用，不代表已经在实体iPhone/Safari上完成键盘兼容验收。未改变库存数量、采购计算或利润公式，也未修改生产MySQL配置。
