# OGL 预估模型与真实物流分离

任务分支基于远程发布分支 `release/2026.10.21-task-brand` 的 `02ad393`。本次代码仅本地验证，尚未部署。

库存明确选择 OGL 后，订单预估优先按订单日期有效的 OGL 陆运规则、包裹重量尺寸及订单货值匹配档位。实际 CEL/FBP 的服务类不再覆盖商品已选择的 OGL 预估模型。现有 OGL 档位选择提取为共用函数，未修改已发布的利润公式或运价算术。

真实账单结算、原始物流记录、仓库和实际发货渠道继续使用既有路径。未选择 OGL 的库存商品保留现有行为；OGL 生效前的历史订单保留原匹配路径。OGL 参数不适用时明确报错，避免悄悄改用 CEL 报价。零克重保留现有 10 克最低计费兜底，库存原克重不被改写。

验证：

- 68 项专项回归通过，包括 6 项新测试、冻结 V1 公式等价、汇率财务费用、结算、当前预估明细及版本事务。
- 隔离 MySQL 验收通过：原始实际物流为 CEL FBP Standard Extra Small，选择 OGL 的商品按 300 克重算为 12.06 元运费和 43.77 元预估利润；实际发货原文不变，企业隔离和历史记录保留。
- 编码及 SQL 绑定检查通过。
- 发货分类、显示来源与运费描述器另有 18 项通过。扩展物流检查的 3 个原有失败已在干净 `02ad393` 基线上复现：物流缓存键版本断言过期，隔离测试 VM 缺少 `readRequestTenantContextMysql` mock，以及分页测试缺少 `orderBindingIgnoreService` mock。未修改相关旧测试。

本次用户授权的生产业务数据切换另有逐行前值备份和计算修订，不属于代码部署：当前企业 847 个库存已使用 OGL，调整 823 个配置；自北京时间 2026-11-01 起更新 1,199 个商品行，涉及 1,192 笔订单。保留真实费用和 11 月之前的订单。零克重 69 笔、未绑定库存 4 笔、缺售价库存 27 个分别导出核对清单。
