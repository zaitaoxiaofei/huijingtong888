# Ozon 中国 rFBS 佣金快照

定价工具和利润计算器读取此目录中生效日期最新的 JSON 文件。每个文件对应一份不可覆盖的工作簿快照；同一生效日期有多个文件时，按 `importedAt` 选择最新导入版本。文件保留原始文件名和 SHA-256，便于追溯。未来生效的版本在生效日之前不会被选中。

导入新版本：

```sh
python3 scripts/import-ozon-rfbs-tariff.py /path/to/Tarifs_CN_*.xlsx
```

脚本需要 `openpyxl`，只读取 `Full ChinaHK` 的 rFBS 三档费率，不导入 FBP。检查输出行数、类目、品牌例外和生效日期后，提交新 JSON 文件；保留旧文件。服务端在下一次请求时读取最新快照，无需修改数据库。若官方表格列结构变化，先更新导入脚本并核对边界价格。

当前来源：用户提供的 `Tarifs_CN_01_12_2025_1761720496.xlsx`，`Full ChinaHK` 工作表，生效日期 2025-12-01。档位为 `0–1500`、`1500.01–5000`、`5000.01+` 卢布。品牌为 `All` 时使用通用费率；Apple、Dyson 等品牌行单独展示，需按实际品牌选择。
